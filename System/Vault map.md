# Vault map

Where things are. Rules are in [[Agent rules]]; the owner's profile is in [[README]].

## Owner's area (human-owned)

- **Notes/**: all notes. A project is a note with the `[[Projects]]` category (there is no Projects folder). Category dashboards: [[Projects]], [[Ideas]], [[Memos]], [[Sources]], [[People]], [[Meetings]]; they are Base views and update themselves.
- **Daily/**: one note per date (`YYYY-MM-DD.md`).
- **Attachments/**: images, PDFs and other files embedded in notes.
- **Templates/**: templates for new notes.
- **System/**: this map, [[Agent rules]], [[Note properties]], [[Agent bootstrap]].

## AI area (AI-owned)

- **AI/Working/**: plans, scratch work, study folders, logs.
- **AI/Proposals/**: drafts waiting for the owner's approval.
- **AI/Memory/**: `Index.md` (catalog; read first) and `Topics/<project>/`, `Topics/Workflow/` (small pages). Changed only by a dream.
- **AI/Dreaming/**: `Queue.md` (entries waiting for the next dream), `Runs/` (reports and snapshots), `Imports/` (raw imported text, not memory).
- **AI/Skills/**: `memory-dreaming`, `obsidian-learning-wiki`.
